--------------------------------------------------------------
DIFFICULTY SCALE
--------------------------------------------------------------
Easy    - Beginner friendly. Slower BPM, simple patterns.
Hard    - Moderate challenge. Fast BPM, complex patterns.
Extreme - Maximum intensity. Very fast with dense arrows.

--------------------------------------------------------------
NOTES FOR CLAUDE CODE
--------------------------------------------------------------
- BPM values determine arrow spawn rate in the game engine.
- Use BPM to calculate beat interval: interval_ms = (60 / BPM) * 1000
- Difficulty maps to arrow pattern density and speed multiplier.
  Easy    -> speed multiplier: 1.0x
  Hard    -> speed multiplier: 1.5x
  Extreme -> speed multiplier: 2.0x
